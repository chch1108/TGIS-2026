# 💧 雲林縣智慧救災決策支援系統 (TGIS)

本專案建置一套適用於雲林縣區域智慧防災決策平台。系統整合淹水模擬資料、人口分布、重要設施位置、避難收容所容量、資源分配演算法及避災路徑規劃功能。

---

## 🚀 啟動方式

請於終端機執行以下步驟安裝環境並啟動服務：

1. **切換至專案根目錄**：
   ```bash
   cd TGIS
   ```
2. **安裝必要套件**：
   ```bash
   pip install -r requirement.txt
   ```
3. **啟動 Streamlit 服務**：
   ```bash
   streamlit run app.py
   ```
   啟動完成後，瀏覽器會自動開啟 `http://localhost:8501` 呈現操作畫面。

## 🖥️ 前端主要功能和操作指引

系統包含五個核心功能分頁，以下為詳細操作指引、參數說明及指標含義：

### 1. 💧 淹水概況呈現 (Flood Overview)
本分頁展示特定颱風最大淹水潛勢圖和防汛淹水動態擴散模擬圖。
* **指標代表意義**：
  * **全縣淹水面積 (km²)**：積水深度超過 30 公分區域總面積。
  * **最大水深 (cm)**：全縣預測最高積水深度。
  * **暴露人口**：居住在積水高度超過 30 公分區域人口總數。
  * **綜合風險指標**：整合全縣淹水範圍、淹水深度、人口暴露和颱風風速強度計算得出風險分數（介於 0 至 100 分範圍內，分級 A 至 D，由低風險至極高風險）。
* **操作及參數**：
  * 在側邊欄選單選擇歷次颱風事件（例如：莫拉克、杜蘇芮等）即可更新全頁資料。
  * 使用者可於側邊欄啟用「自訂颱風」，輸入自訂名稱、年份、風速及暴風半徑以模擬自訂氣象情境。

### 2. 🏥 關鍵設施風險 (Facility Risk)
本分頁評估全縣醫院、長照機構、變電所和收容所受淹水衝擊風險狀態。
* **圖表呈現和燈號意義**：
  * 地圖上以不同圖標表示設施：🏥 醫院、🏠 長照中心、⚡ 變電所、🤍 收容所。
  * **燈號顏色代表淹水嚴重程度**：
    * 🟢 無淹水 (0cm)；
    * 🟡 輕微積水 (<30cm)；
    * 🟠 中度淹水 (30-70cm)；
    * 🔴 嚴重淹水 (70-100cm)；
    * 🟣 極嚴重淹水 (>100cm)。
* **操作及參數**：
  * 可透過核取方塊篩選是否顯示特定類型設施。
  * 提供互動式風險評估統計表格，點擊欄位標頭可進行排序。

### 3. 🚦 資源分配最佳化 (Resource Allocation)
使用遺傳演算法 (GA) 和蟻群演算法 (ACO) 最佳化配置移動式抽水機並規劃最佳行駛路徑。
* **操作參數說明**：
  * **抽水機數量**：本配置可用移動式抽水機總台數（可調範圍 5 至 20 台）。
  * **GA 演化代數**：遺傳演算法反覆疊代代數（可調範圍 30 至 200 代，越高運算時間越長但解更精確）。
  * **車庫緯度 / 車庫經度**：起點車庫座標位置，預設自動計算高風險區域幾何中心。
* **指標代表意義**：
  * **GA 風險覆蓋分**：GA 部署方案覆蓋淹水社會風險總分數，越高代表防護越有效。
  * **總路線距離**：車輛從車庫出發依序抵達各部署點位，最後停在最後一個站點開路規劃總里程數（公里）。

### 4. 🚧 避難引導路徑 (Evacuation Routing)
比較傳統幾何最短路徑和本系統所提類強化學習 (RL) 避災路徑。
* **操作參數說明**：
  * **起點地址 / 終點地址**：輸入雲林縣內完整地名或門牌地址，按「計算建議路徑」進行規劃。
* **指標代表意義**：
  * **Dijkstra 最短路徑 (紅色)**：僅依幾何距離計算，極易引導居民穿越淹水高風險區域。
  * **RL 避災路徑 (綠色)**：依據預測水深動態調整阻抗，自動繞避積水區。若淹水達 100 公分即標記阻斷不可通行，優先確保撤離安全。
  * **額外行駛里程 (km)**：RL 避災路徑因繞道所增加行車距離。
  * **淹水暴露削減 (cm)**：RL 避災路徑相較幾何最短路徑降低平均積水暴露深度。

### 5. 🏠 收容分流管理 (Shelter Management)
透過 KD 樹空間分析，模擬預測淹水災民前往最近官方收容所人流分流狀況。
* **收容所燈號狀態意義**：
  * **🟢 充裕**：預估收容人數低於總容量 60%。
  * **🟠 接近飽和**：預估收容人數介於總容量 60% 至 90% 範圍。
  * **🔴 超載**：預估收容人數大於等於總容量 90%，警示需進行分流調整。
* **操作及參數**：
  * **疏散率 (Evacuation Factor)**：模擬災民前往收容所比率（預設為 5%）。
